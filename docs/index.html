bank-account.spec 
var balance: int
var frozen:  bool

init { balance = 0  frozen = false }

action deposit(amount: int) {
  require amount > 0
  balance' = balance + amount
}
action withdraw(amount: int) {
  require amount > 0
  require balance >= amount
  require frozen == false
  balance' = balance - amount
}
action freeze   { frozen' = true  }
action unfreeze { frozen' = false }

invariant solvency { balance >= 0 }
temporal liveness {
  always (frozen == true -> eventually frozen == false)
}
What Spectre does

What Spectre can do

From modelling a state machine to catching bugs before they ship.

🔍

Exhaustive state exploration

BFS explores every reachable state. Spectre reports the exact action sequence that triggers a bug — not just that one exists.

⚡

Bounded model checking (Z3)

Encode your spec as SMT-LIB2 and find shallow bugs instantly with Z3 — no full state graph needed. Scales to huge specs.

🔄

SMT-backed drift detection

spectre sync classifies each changed action as structurally unchanged, SMT-proved equivalent, or semantically changed — with a counterexample witness.

🧬

Spec mining

Extract a Spectre skeleton from existing Rust source automatically — fields become variables, methods become actions, guards are inferred.

🧪

Model-based testing

Generate ITF traces, Rust test drivers, and replay harnesses. Five coverage modes including property-directed steering.

🛡️

Runtime monitoring

Generate a self-contained monitor.rs that checks all spec invariants in production — O(k) per step, zero external dependencies.

⚙️

Incremental re-verification

When one action changes, re-verify only that action without rerunning full BFS. 4–5× faster on Raft (22k states).

🗜️

Partial-order reduction

--por skips redundant interleavings using the ample-set heuristic. 3-node Raft: 22,432 → 6,818 states (7.6× reduction).

🎯

Property-directed exploration

Best-first BFS steers toward invariant boundaries — finds all 29 violations in a queue spec in 204 states vs. 150k random steps.

Verification backends

Choose your backend

Switch backends with a single flag — same spec, different trade-offs.

Built-in

BFS

Default. Exhaustive exploration. Zero dependencies. Best for learning and small-to-medium specs.

--backend z3

Z3 BMC

Bounded model checking via SMT. Finds shallow bugs fast in large state spaces. Requires z3 binary.

--backend tlc

TLC

Exhaustive TLA+ model checker. Required for liveness and fairness properties. Requires Java + TLC jar.

--backend apalache

Apalache

Symbolic model checker via Z3. Handles large state spaces exhaustively. Requires Java + Apalache.

Getting started

Install Spectre

Download a pre-built binary or build from source in under a minute.

1

Download the binary

Get the latest release for your chip from the Releases page.

# Apple Silicon (M1/M2/M3)
curl -LO https://github.com/BoundlessProducts/spectre/releases/latest/download/spectre_darwin_arm64.tar.gz
tar xf spectre_darwin_arm64.tar.gz

# Intel Mac
curl -LO https://github.com/BoundlessProducts/spectre/releases/latest/download/spectre_darwin_amd64.tar.gz
tar xf spectre_darwin_amd64.tar.gz
2

Install globally

sudo mv spectre /usr/local/bin/
spectre --help
3

Optional: install Z3 for drift detection

brew install z3
4

Verify your first spec

spectre verify examples/bank-account-violation.spec
# Finds invariant violation in one step
